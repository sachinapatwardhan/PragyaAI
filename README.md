# Pragya AI

> **Transforming Data into Wisdom**

Pragya AI is an Enterprise AI Copilot Platform that enables organizations to interact with their existing databases, documents, reports, and business systems using Artificial Intelligence.

## Vision

To transform enterprise data into actionable knowledge without replacing existing business applications.

## Technology Stack

- .NET 10
- ASP.NET Core
- Blazor Server
- Entity Framework Core
- SQL Server
- Microsoft Semantic Kernel
- OpenAI / Azure OpenAI
